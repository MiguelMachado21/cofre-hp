# Cofre Mágico 🪄

Controle financeiro pessoal simples, com visual de escola de magia.

- Entradas e saídas, já realizadas ou previstas (a receber / a pagar)
- Resumo do mês, saldo previsto e lançamentos repetidos
- Gráficos dos últimos 6 meses e por categoria
- Funciona offline e pode ser instalado na tela inicial do celular

Os dados ficam salvos apenas no navegador do aparelho (localStorage).
Use **Ajustes → Baixar backup** de vez em quando.
